# Waypoint WiPay for OpenCart

An independent OpenCart payment integration project maintained by Waypoint. It is not affiliated with, sponsored by, or endorsed by WiPay.

## Project status

**Research and legacy review only.** This is not a current, supported release. The supplied archive identifies OpenCart 3.0.3.2 and includes an old callback rewrite instruction. Review its code, license/provenance, routing, and API behavior before reuse.

## Direction

The intended integration would redirect shoppers to WiPay's hosted checkout and verify responses server-side. The store should not collect card details. OpenCart 3.x and 4.x support targets are not yet selected.
